## ✨ Возможности

- 🕵️‍♂️ Сбор сообщений из **любой супергруппы**, где вы участник
- 🔗 Автоматическое построение **цепочек ответов** (`reply_to_message`)
- 📅 Группировка обсуждений **по дням недели**
- 📊 Подсчёт:
  - Количества сообщений в обсуждении
  - Уникальных участников
  - Автоопределение "темы" по первому сообщению
- 🌍 Поддержка любого часового пояса (по умолчанию: `Asia/Tashkent`)

## 🚀 Быстрый старт

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/ваш-ник/telegram-discussion-analyzer.git
   cd telegram-discussion-analyzer
   ```
2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```
3. **Настройте окружение**
   ```bash
   cp env.example .env
   ```
**Отредактируйте .env:**
- Получите API_ID и API_HASH на "my.telegram.org/apps"
- Укажите GROUP_ID вашей супергруппы (пример: -1001234567890)

4. **Запустите анализ одной командой**
   ```bash
   python main.py
   ```
При первом запуске потребуется ввести номер телефона и код из Telegram.

5. **Результат**
>Готовый отчёт появится в data/report.json

## ⚙️ Конфигурация

| Переменная    | Обязательная | Пример                     | Описание |
|---------------|--------------|----------------------------|---------|
| `API_ID`      | ✅ Да        | `1234567`                  | ID вашего Telegram-приложения (получить на [my.telegram.org/apps](https://my.telegram.org/apps)) |
| `API_HASH`    | ✅ Да        | `a1b2c3d4e5f67890abcdef1234567890` | Секретный хеш приложения (тот же источник) |
| `GROUP_ID`    | ✅ Да        | `-1001234567890`           | ID супергруппы (начинается с `-100`; узнать можно через пересылку сообщения → ссылка вида `t.me/c/1234567890/...` → ID = `-1001234567890`) |
| `TIMEZONE`    | ❌ Нет       | `Asia/Tashkent`            | Часовой пояс для отчёта (по умолчанию: `Asia/Tashkent`; список: [pytz timezones](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones)) |

## 📤 Формат отчёта

Результат анализа сохраняется в файл `data/report.json` в следующем формате:

```json
{
  "timezone": "Asia/Tashkent",
  "days": [
    {
      "date": "2025-10-15",
      "threads": [
        {
          "topic": "Как подключить CarPlay?",
          "messages": 12,
          "users": 5
        },
        {
          "topic": "[Медиа или пустое сообщение]",
          "messages": 3,
          "users": 2
        }
      ]
    }
  ]
}
```

## 💡 Примечания

- Скрипт использует **пользовательский аккаунт** (через MTProto), а не Telegram Bot API — это необходимо для доступа к цепочкам ответов (`reply_to_message_id`) в приватных супергруппах.
- Текущая реализация **не поддерживает форум-группы (topics)** — анализ строится на основе reply-цепочек. Поддержку topics можно добавить при необходимости.
- При работе с крупными группами возможны **ограничения Telegram (FloodWait)** — скрипт автоматически обрабатывает такие ошибки и делает паузу.
- Тема обсуждения (`topic`) формируется из **первого сообщения цепочки** (урезается до 50 символов, переносы заменяются на пробелы).
- Для корректной работы **ваш аккаунт должен быть участником целевой супергруппы**.
